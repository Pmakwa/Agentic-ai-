Supervisor:

1.   User intent determine karega.

2.   Request classify karega.

3.   Risk level determine karega.

4.   Relevant memories identify karega.

5.   Memory authority check karega.

6.   Conflicting information identify karega.

7.   Task ko decompose karega.

8.   Agents select karega.

9.   Agent permissions verify karega.

10.   Tools select/authorize karega.

11.   Execution dependencies manage karega.

12.   Agent outputs compare karega.

13.   Unsupported claims detect karega.

14.   Hallucination risk detect karega.

15.   Final answer verify karega.

16.   High-risk actions ko gate karega.

17.   Errors ke propagation ko stop karega.

18.   Required rollback initiate karega.

19.   Approved learning ko memory pipeline mein bhejega.

20.   Final response release karega.
