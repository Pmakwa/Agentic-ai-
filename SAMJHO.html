UAI-COS — 2 minute me samjho

Ye ek AI ka dimaag + yaad-dasht system hai. Maine ise tumhare V2 prompt se banaya hai, aur ye abhi tumhare workspace me chal raha hai (sirf likha hua nahi).

1. Ye kya karta hai (ek line me)

Jo baat tum bolo — wo yaad rakhta hai, usme se rules aur preferences nikalta hai, aur agli baar wahi use karke kaam karta hai. Par har baat blindly nahi maanta — source, date, confidence aur scope check karta hai. 🙌

2. Kaam kaise karta hai — 5 step

1
Padho
Tumhari baat sunta hai aur dekhta hai: kaam kis type ka hai, kitna risky hai.
2
Yaad se nikaalo
Sirf kaam ki memory nikalta hai (poora dump nahi). Tumhare rules ko sabse upar rakhta hai.
3
Kaam karo
Plan banata hai, phir file/code/image/prompt banata hai. Kuch delete ya bhejna ho to pehle permission maangta hai.
4
Check karo
Chhoti galtiyaan bhi pakadta hai — jaise bina source ka fact, ya galat memory ka use.
5
Yaad rakho
Nayi baat ko memory me likhta hai. Purani baat delete nahi hoti — nayi version banti hai (history rehti hai).

4. Tum ise kaise use karoge (asli udaharan)

  • Image prompt maango → tumhare purane rules (photorealism, product-only me model/haath nahi) khud lag jaayenge.
  • Kaho "yaad rakhna: client ko GST breakup chahiye" → memory ban jaayegi, agli baar proposals me khud dikhega.
  • Kaho "purana data delete kar do" → pehle permission maangega, warna archive karega (wapsi ho sake).
  • Galti batao → turant sudharega, aur chahe to permanent rule bana lega.

5. Ek zaroori sach (jhooth nahi bolo)

Ye yaad-dasht is workspace ki files me save hoti hai. Tumhare doosre chat/app me apne aap nahi jaati — uske liye main ek prompt file banata hoon jo wahan paste karni padegi (00_SYSTEM/UAI-COS_SYSTEM_PROMPT_standard.md). Isliye "unlimited permanent memory" jaisi baat main nahi karta. 😌
Bas ab ek cheez bolo — kya karna hai?
  • "Kaam do" → koi bhi kaam bolo, main isi system se karunga
  • "Telegram" → token do, mobile se chalne wala bot live kar deta hoon
  • "Aur simple karo" → jo samajh na aaya wo aur aasan bhasha me likh deta hoon
